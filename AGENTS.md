# AGENTS

## Branch Rule
- Before starting work, check the current Git branch.
- If the current branch is `main`, create and switch to a new feature branch before making task changes.

## Completion Rule
- After completing any task mapped in `PROJECT_TEMPLATE_PLAN.md`, update that file in the same change to mark the completed item.
- After completing the task, commit the relevant work and push the branch to the remote.

## Documentation Rule
- If a change affects setup, workflow, or expected behavior, update the relevant documentation before closing the task.
